# 黑客松大赛赛历设计文档

黑客松大赛赛历是一份未来一年的 Hackathon 和 AI 比赛清单。打开就能按时间往下看，筛完再点进一场，返回后筛选和滚动位置都还在。

线上地址：https://www.51winwin.com/Hackathon

## 给谁用

想在接下来一年里带不同年龄的人参加比赛，尤其是孩子。同一年里可能既看小学阶段，也看大学和成年人，所以年龄是多选，不是单选。

也要能分清这场是线上、线下，还是线上加线下，以及它算黑客松、AI 创新赛，还是某个具体板块。

## 页面

三个画面：

1. 清单。默认页。中国区在上，国际区在下。
2. 日历。同一套筛选下的月历，点某一天再看当天的场次。
3. 详情。一场比赛的报名、时间、年龄、板块和介绍。

顶部是标题「黑客松大赛赛历」、上次更新时间，以及「清单 / 日历」和「更新全部」。标签页图标是黑底、纸色竖条、赤陶横条组成的 H。

## 一场比赛要让人扫一眼看懂

清单每一行从左到右：

- 日期，和这日期是什么意思：报名截止、提交截止、开赛日、进行中、今天结束、还有几天结束。快到期用强调色。
- 英文名，下面一行中文名。中文原名不再另译一行。
- 形式。线下和混合再带城市。
- 类型、年龄、板块。选中的板块排在标签前面。

没有截止日期、已经结束的报名，不伪装成「今天截止」。正在进行、但开赛日已经过去的，显示结束日，并写「进行中」「今天结束」或「n 天后结束」。

详情里写形式、报名、举办日期、年龄、类型和板块、主办、奖金、来源。正文里的中文句号 `。` 和分号 `；` 后面换行。英文句号和网址不换行。

## 时间范围

只收「还没结束，并且开始日在今天起 365 天内」的比赛。日期用 `YYYY-MM-DD`，今天按上海时区。

清单上的时间筛选看的是这一行展示出来的那个日期，不是整段活动随便搭到窗口上：

- 本月：展示日期落在本月。
- 近三月、近半年、近一年：从今天起 90、180、365 天。
- 近一年额外留下「展示日期已过，但结束日仍在窗口里」的场次，这样进行中的比赛还在。

默认是近一年。

## 排序

中国区和国际区分开排，规则相同：

1. 还开着的报名或提交截止，近的在前。
2. 没有截止日、或正在进行的，按结束日排在开放截止日后面。
3. 报名已截止、比赛还没完的，再靠后。
4. 同一天按标题。

## 筛选

筛选写在网址里。从详情返回、或刷新这一页，条件都还在。改筛选时页面不跳回顶部。

| 条件 | 默认 | 规则 |
| --- | --- | --- |
| 时间 | 近一年 | 本月、近三月、近半年、近一年 |
| 只看报名中 | 关 | 去掉报名已截止的 |
| 形式 | 线上、线下、线上加线下都开 | 多选 |
| 国家 | 全部 | 单选 |
| 年龄 | 大学、成年人、年龄未标明 | 多选。小学、初中、高中默认不勾 |
| 板块 | 全部 | 多选时，命中其中任意一个板块就留下 |

板块是「或」，不是「并且」。一场比赛可以同时带开源和硬件。只选硬件时，没有硬件标签的会被拿掉；同时选了硬件、开源、Web3、大厂时，只要占其中一项就还在。所以前几行有时看起来没变，但场数会变，标签也会把选中的板块放到前面。

国家名单只列出当前筛选下真有场次的国家。时间、形式、年龄、板块、只看报名中变了以后，下面已经没有场次的国家会从下拉里消失。选中一个国家时，其他仍有场次的国家还留在下拉里，方便改选。罗马尼亚和印度不出现，这两国的场次也不进入清单。线上地点不单算一个国家。

选完筛选再点进详情，返回后停在原来的滚动位置，方便接着往下看。

清单按每页 10 场分页，中国区和国际区分开翻页。页码写在网址里（`cp`、`wp`），返回详情后还停在那一页。改筛选会回到第 1 页。日历不按页切开，仍用当前筛选下的全部场次。

## 日历

周一为一周的第一天。今天的日期是实心圆。若这一天有临近截止的比赛，圆用强调色。

短活动（结束不晚于开始后 4 天）标在它覆盖的每一天。更长的活动只标一个点：优先截止日，否则开始日，否则结束日。避免一整月都被同一场比赛铺满。

手机上不把比赛名塞进格子，只显示当天有几场，并写明这个数字是当天的比赛场数。日历下面按日期列出这个月有比赛的每一天。点某一天，清单滚到那一天；这一天没有比赛时，清单里写「这一天没有比赛」。电脑上格子里仍是比赛名，点日期同样滚到下面的清单。

## 访问统计

页面打开时记下一次浏览，离开或切到别的页面时记下停留时长。同一浏览器算一个访客（UV），一次打开算一次浏览（PV）。关掉浏览器再打开算新的一次访问，用来算平均页数和平均停留。统计页自己的打开不记入。原始记录在 `data/visits.jsonl`，汇总在 `/stats`。时间按东八区，可选今日、近 7 天、近 30 天、自定义起止日期和全部，选中的范围写在网址里。UV、PV、平均停留和平均页数都按这一段重算。单次页面停留最多记 30 分钟。

## 来源

更新时按来源去拉，写进 `data/events.json`。按钮在抓取过程中停用，文案是「正在全网搜索」。

会尝试这些来源：

- HackerTrip
- Devpost
- MLH
- DoraHacks
- ETHGlobal
- DrivenData
- lablab
- 魔搭
- connpass（日本。对方的 JSON 接口会拒绝访问，改抓搜索页里未来一年、标题里带黑客松的活动。说明会、后夜祭、应援和成果发表会不收）
- EventUs（韩国。搜索「해커톤」，只要标题里是黑客松的活动）

天池的接口一直返回 HTTP 403，已经从抓取里拿掉，页面上不再显示这一行。不要手填天池的比赛。

抓回来是 0 场、也没有报错的来源不显示。

同一场比赛在多个来源出现时合并成一条，来源名叠在一起。合并看标题是否是同一场，以及去掉年份、届数后的名字是否够像、开始日是否在 14 天内。不把只是都叫黑客松的比赛并成一场。

英文标题会译成中文。译名进 `data/translations.json`，译坏的不留在页面上。

## 字和版式

标题和正文都用无衬线：微软雅黑优先，接着是苹方、冬青黑体、Noto Sans SC。不再用宋体或 Noto Serif。Mac 和手机上如果没有微软雅黑，会落到苹方或 Noto Sans，看起来仍是黑体，不是宋体。

底色是暖纸色，字是近黑，临近截止用赤陶色。电脑上清单是一行四列。宽度低于 900px 时改成上下堆叠，筛选换行，日历格子改成场数。

## 刷新和部署形态

本地开发在网站根路径。线上挂在 `/Hackathon`，由 `NEXT_PUBLIC_BASE_PATH` 在构建时写进页面和接口地址。旧地址 `/hakerthon` 会跳到新地址。

「更新全部」请求 `POST /api/refresh`，用服务端事件流报告正在抓哪个来源。同一时间只跑一次，第二次会被告知已经有更新在进行。
