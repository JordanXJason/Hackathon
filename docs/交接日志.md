## 本地

```bash
npm install
npm run dev
```

更新清单（会访问各个来源，大约一分钟）：

```bash
npm run refresh
```

或在页面上按「更新全部」。抓取时按钮不可按，文字是「正在全网搜索」。

## 发布到服务器

在本机提交并推送之后：

```bash
ssh myserver
cd /opt/sai-li
git pull
export NEXT_PUBLIC_BASE_PATH=/hakerthon
npm ci
npm run build
pm2 restart sai-li
```

`pm2 save` 已经做过，机器重启后会拉起。nginx 不用为普通发版再改。

改完用这两条确认：

```bash

curl -sI https://www.51winwin.com/
```

第一条应是 200，正文里有「赛历」。第二条是原来的主站，不要被这次发版改掉。

## 数据

- `data/events.json`：当前清单和各来源的抓取结果。
- `data/translations.json`：英文标题的中文译名。
- 页面每次请求读这两份文件，没有单独的数据库。

## 筛选记在网址里

返回详情时靠这个，不靠内存。

- `time`：`month` `quarter` `half`。缺省是近一年。
- `format`：`online,offline,hybrid`。缺省是三个都要。
- `ages`：缺省是大学、成年人、未标明。
- `sectors`：缺省是全部，有值时命中任意一个即可。
- `country`：缺省全部。罗马尼亚、印度被排除。
- `open=1`：只看报名中。
- `view=calendar`：日历。
- `month=YYYY-MM`：日历翻到的月份。
- `cp`、`wp`：中国区、国际区的页码，每页 10 场。缺省是第 1 页。改筛选会清掉这两项。

点进一场时，另外把滚动位置记在这个标签页的 sessionStorage（`sai-scroll`）。返回后滚回该位置，筛选仍以网址为准。
